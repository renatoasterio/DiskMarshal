## Design

The interface follows an interactive prototype: [`design/prototype/index.html`](../design/prototype/index.html). Open it in a browser. Each screen has its own address, such as `index.html#cleanup` or `index.html#disk-map`.

The images in this documentation are in [`assets/`](assets/). [CONTRIBUTING.md](../CONTRIBUTING.md#updating-the-screenshots) explains how to regenerate them.
